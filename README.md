# 패킷 길찾기 — 방화벽 정책 시뮬레이터

4구역(인터넷·DMZ·내부망·개발·운영 서버망) 토폴로지에서 방화벽 정책표를 편집하고,
패킷이 어느 규칙에 걸려 허용·차단되는지(first-match)를 확인하는 브라우저 단독 앱.

- 판정·점검 규칙: [SPEC.md](SPEC.md)
- 데이터·구조·구현 단계: [docs/PLAN.md](docs/PLAN.md)

## 실행
```
python3 -m http.server 8080   # 후 http://localhost:8080 접속
node tests/run.mjs            # 테스트
```
빌드·의존성 없음(순수 JavaScript ES 모듈).
`index.html` 을 더블클릭(file://)으로 열면 브라우저가 ES 모듈 로딩을 막으므로 위처럼 로컬 서버로 여세요.

## 화면 구성
- **네트워크 구성**: 4구역과 호스트. 패킷 시험 후 출발 구역(파랑)·목적 구역(주황)이 강조된다.
- **정책표**: 추가(위치 지정)·수정·삭제·▲▼ 이동. 판정 때 비교한 규칙은 회색, 걸린 규칙은 초록으로 표시된다.
- **패킷 시험**: IP·프로토콜·포트 입력 또는 예제 7개(함정 2 포함). 규칙별 비교 과정이 나온다.
- **정책 점검**: 섀도잉·중복·기본 거부·syslog 표준 포트. 항목을 누르면 관련 규칙이 강조된다.
- **변경 이력**: 추가·수정·삭제·이동이 자동 기록된다(최신이 위, 변경 전·후 펼쳐보기).
- 정책표와 이력은 브라우저 localStorage 에 저장되고, JSON 으로 내보내기·가져오기·초기화가 가능하다.

## 코드 구조
```
src/core/   판정·점검·이력 (DOM 비의존 순수 모듈)
  topology  구역·호스트·그룹, IPv4/CIDR      parse     주소·서비스 파싱과 검증
  matcher   first-match 판정                 analyzer  covers, 섀도잉·중복·기본 거부·syslog
  policy    규칙 변경 + 이력 + 저장·복원     history   변경 이력 항목
src/ui/     화면 (format·storage 는 DOM 비의존, main 은 document 주입형)
tests/      node tests/run.mjs — 함정 3종(traps.test.mjs) 포함
```

## 배포 (GitHub Pages)
정적 파일뿐이라 빌드가 필요 없다. 저장소 Settings → Pages → Source 를 `main` 브랜치 `/ (root)` 로 지정하면
`https://<사용자>.github.io/fw_simulator/` 로 열린다. (`.nojekyll` 포함)

## 한계
- 규칙은 IPv4, TCP/UDP 만 다룬다(ICMP, IPv6, 상태 추적·NAT 은 범위 밖).
- 섀도잉·중복은 규칙 하나가 다른 규칙 하나를 완전히 덮는 경우만 찾는다(여러 규칙이 합쳐서 덮는 경우는 미검출).
- 화면 모양은 자동 테스트로 확인되지 않는다(로직·이벤트 흐름만 가짜 DOM 으로 검증).
